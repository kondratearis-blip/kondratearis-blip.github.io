KOKORO — 最初のWebサイト

スクロールに合わせて組み上がるコンボトレー、公平な抽選付きのInstagramチャレンジ、ファンギャラリー、ブラウザゲーム。

経緯

KOKOROのために最初に制作したサイトで、その後のすべてのプロジェクトの出発点になりました。

担当：デザイン、実装、Supabaseバックエンド、Instagram連携。

クライアント
KOKORO
時期
2026年10月
技術スタック
HTML · CSS · JavaScriptSupabase (Edge Functions, pg_cron)Instagram APICanvas 2D

制作内容

  1. 01スクロールに合わせて組み上がるSVGのコンボトレー。
  2. 02チャレンジ参加者をInstagramのコメントから10分ごとに取り込み（Instagram API＋Supabase Edge Function）、crypto.getRandomValuesで抽選。1つのニックネームにつきチャンスは1回。
  3. 03アップロード、圧縮、モデレーション機能付きのファンアートギャラリー。
  4. 04Canvas 2Dで制作したブラウザゲーム「KOKORO Courier」（週間ランキング付き）。

結果

2026年10月に約1週間公開した後、事業がオンライン注文に移行したため、同じURLで注文ページに置き換えられました。この注文ページが、のちに注文プラットフォームへと発展しています。

学んだこと

3D版を最後まで作り込みましたが、「最初の方が良かった」と不採用になりました。大きなスタイル変更の前には、まずモックアップを1画面見せるようにしています。
