CHIKKENOFF — フライドチキンチェーンのWebサイト

ドラッグで操作できるコンボの動画カルーセル、全メニュー、「営業中」をリアルタイム表示する8店舗、2タップで完了するWhatsApp注文。

chikkenoff.netlify.app↗

経緯

チェーンの紙のメニューカードをモチーフにした、遊び心のあるワンページサイトです。サイトに長く留まる人のためにミニゲームも用意しました。

担当：コンセプト、デザイン、実装を担当。コンセプトは、AIエージェント3体が出した案を審査役のAIエージェント3体が評価する合議方式で選びました。

クライアント
ビシュケクのフライドチキンチェーン向けコンセプト（自主提案）
時期
2026年10月
技術スタック
HTML · CSS · JavaScriptCanvas 2Dffmpeg (video grid)Spec Kit

制作内容

  1. 01「シリンダーウォール」型カルーセル：形状を毎フレーム計算し、各カードはcanvasを内包したclip-pathのボタンとして実装。
  2. 02非表示の5×2動画グリッド1本を10個のcanvasに描画。1つのデコーダーで全カードの同期を維持。
  3. 03オーナーのメニューカードに基づく価格付きの全メニュー。1つのデータファイルを唯一の情報源（source of truth）として管理。
  4. 04ビシュケク時間に基づく8店舗の「営業中」表示と、2タップで完了するWhatsApp注文。
  5. 05Canvas 2Dのミニゲーム「チキンを倒せ」：3レーン、最大×5の倍率、ハイスコア。容量は38 KB。

結果

完成し、chikkenoff.netlify.appで公開中です。
