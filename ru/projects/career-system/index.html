ARIS Japan Career System

Платформа, на которой работает этот сайт: закрытая CRM для моего поиска работы с ИИ-исследованием компаний, шестью типами писем и Gmail с двухэтапным подтверждением.

О проекте

Публичная часть — портфолио, которое вы сейчас читаете. Закрытая часть ведёт компании, вакансии и контакты — каждый факт хранится со статусом проверки и источником — и готовит честные письма, которые я подтверждаю по одному.

Моя роль. Всё: спецификация, модель данных, бэкенд, интеграция с ИИ, интеграция с Gmail, безопасность, тесты.

Что сделано

  1. 01Next.js 16 App Router, React 19 и TypeScript; PostgreSQL с миграциями Drizzle.
  2. 02Факты хранятся как значение + статус (подтверждено, не проверено, неизвестно) + источник — визовое спонсорство никогда не считается само собой разумеющимся.
  3. 03Claude API со структурированным выводом для исследования компаний и шести типов писем.
  4. 04Жёсткие проверки до любой отправки: никаких ссылок-заглушек, выдуманных дипломов или уровня позиции, одно первое письмо на компанию — в коде и уникальным индексом в базе данных.
  5. 05Gmail OAuth с PKCE, хеш подтверждения, который ломается при любой правке, пробный режим (dry-run) по умолчанию и отправка в три шага с резервированием.
  6. 06Черновики повторных писем через 5–7 рабочих дней, генератор резюме с экспортом в PDF, чек-лист соответствия визовым требованиям.
  7. 07Независимое ревью безопасности: исправлено шесть находок, включая SSRF через IPv6, DNS rebinding и подмену прокси-заголовков.

Итог

Использую для своих откликов. Письма уходят только после того, как я подтвержу каждое.
